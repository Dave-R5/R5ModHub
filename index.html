    Instellingen

    Eigen Twitch-app gebruiken (geavanceerd)
    Hoe maak ik een Twitch-app voor de Client ID?
    1. Open dev.twitch.tv/console/apps en klik op Register Your Application (Toepassing registreren). Je hebt tweestapsverificatie op je Twitch-account nodig.
    2. Naam: vrij te kiezen, bijv. Modview Dave.
    3. OAuth Redirect URL (omleidings-URL), precies zo, met de slash aan het eind:
    4. Categorie: kies Chat Bot.
    5. Clienttype: kies Openbaar / Public. Niet Vertrouwelijk / Confidential.
    6. Klik op Create (Maken), daarna bij je app op Manage (Beheren).
    7. Kopieer de Client ID en plak hem hierboven. Klik dan op Inloggen met Twitch.

    Berichten met deze woorden worden rood gemarkeerd. Aan- en uitzetten doe je in de chat via ⚙ Chat.

    Cloud-back-up (via GitHub)

    Je instellingen, sneltoetsen, notities, woordfilter en modlog worden bewaard in een geheime gist op je eigen GitHub-account. Zo zet je alles in één klik over naar een ander apparaat.

    1. Maak op GitHub een token: github.com/settings/tokens/new. Alleen het vinkje gist is nodig. Kies bij Expiration bijv. No expiration.
    2. Plak de token hieronder en klik op Naar cloud. Op een ander apparaat plak je dezelfde token en klik je op Uit cloud.

    Hoe wil je bekijken?

    Onderin wissel je altijd tussen Chat, Knoppen en Kijkers (je sneltoetsen en chatcommando's).
